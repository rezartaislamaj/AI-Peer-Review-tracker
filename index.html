How this page works

This table extends Table 2 from the manuscript. New studies are added periodically as they are published; see the repository README.md for how to propose an addition. Tier tags reflect where each study's findings contribute in the three-tier framework (Tier 1: automated verification, Tier 2: supervised assistance, Tier 3: human-led judgment). Many studies findings cover more than one tier. Positive findings are marked in green, and negative findings are marked in red.

To suggest a study for inclusion, open an issue or pull request against this repository following the format in studies-data.js. This page is a research resource.
