How this page works

This table is the maintained version of Table 1 in the manuscript. All publishers listed prohibit uploading manuscript content to external AI tools; the table summarizes what distinguishes each policy. Strictness combines permitted scope (none → language only → summarization/drafting) and disclosure burden (none → report → editor and report). Because publisher pages are reorganized often, this page is maintained alongside the study tracker so links and policy summaries can be corrected as venues update their guidance.
